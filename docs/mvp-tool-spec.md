# 鼠類防治管理工具 MVP 規格（黑客松 demo）

確認日期：2026-10-24。所有決定逐項確認；標示「技術預設」者為實作時的預設值，可在設定頁調整。

## 1. 頁面與版面
- 工具做在 three.js 模型頁 `dist/model.html`；資料地圖 `index.html` 維持現狀，作為方法說明。
- 版面：左側分頁面板「圖層｜任務｜回報」；點選里或任務時右側滑出資訊卡；底部橫向時間軸，標出任務與回報日期；右上角為身分選單與設定齒輪。

## 2. 動態模型（族群模型）
- 全市切成網格（技術預設 100 m，約 2.7 萬格），於瀏覽器逐日推算。
- 承載量 K：由環境因子（污水人孔、雨水人孔、攤販集中場、傳統市場、餐飲業者、垃圾車停靠點）計算，對應設定頁的「範圍、強度、飽和」。
- 族群 N 依「增加程度」以 logistic 方式朝 K 回升。
- 任務：依類型扣族群或降承載量，並把部分族群外溢到範圍外的環帶。
- 回報：以回報座標為中心、依距離遞減地提高估計，隨時間衰減。
- 只有溝鼠進模型；屋頂鼠、小家鼠、不確定只顯示回報點（預設只勾溝鼠）。

## 3. 時間軸
- 過去 90 天到未來 30 天，以天為單位；從 90 天前的平衡狀態開始推算；今天以後為預測。
- 設定頁有隱藏開關，可關閉時間軸，只顯示今天的狀態。

## 4. 熱區顯示
- 預設顯示族群指數（橘到深紅）。
- 可切換「變化」模式：與環境基準相比，藍色為被壓低、紅色為升高（回報或外溢）。

## 5. 里
- 456 里界（民政局），放大後顯示細線。
- 可切換「里分級著色」：把網格風險彙總到里後分級著色。
- 點選里開資訊卡：風險、近期回報數、進行中任務。

## 6. 任務
**範圍**：以里為單位多選（先選區再勾里，或點模型上的里）。不做涵蓋比例；單獨市場的清消另外處理（之後設計）。資料結構預留多邊形：

```json
{ "scope": { "type": "villages", "villages": ["6300500020"], "geometry": null, "boundaryVersion": "2026-09" } }
```

**類型與模型影響**（各自一組參數）

| 類型 | 對族群 N | 對承載量 K | 外溢 |
|---|---|---|---|
| 投藥 | 一次扣除高比例 | 不變 | 低 |
| 環境清消 | 小幅扣除 | 暫時降低（食源清除），數日後恢復 | 高 |
| 捕鼠籠 | 小幅扣除，持續於執行期間 | 不變 | 低 |
| 填補鼠洞 | 不變 | 長期降低 | 中 |

**外溢**：任務範圍（里的合併範圍）外一圈環帶（技術預設 300 m），外溢族群依環帶內各格承載量分配。

**欄位**

| 欄位 | 說明 |
|---|---|
| 案號 | 手填或自動產生 |
| 類型 | 投藥、環境清消、捕鼠籠、填補鼠洞 |
| 範圍 | 里清單 |
| 執行時間 | 起訖日期 |
| 執行單位 | 區清潔隊（再選分隊）、環保局水質病媒管制科、市場處、外包除鼠公司（廠商名稱、合約編號）、其他（自填） |
| 配套措施 | 鼠屍清理、殘餘藥物回收，各自預定日期與完成狀態 |
| 藥劑 | 投藥任務填藥劑種類（第一代、第二代抗凝血劑等）與投藥點數 |
| 經費 | 預算或實際支出 |
| 民眾通知 | 是否通知、方式、通知日期 |
| 狀態 | 規劃中、執行中、已完成、已取消 |
| 建立者與修改紀錄 | 依身分自動帶入 |

**猛禽二次中毒提示**：投藥任務範圍外擴（技術預設 1 km）內有鳳頭蒼鷹紀錄（技術預設 2016 年以後）時提示風險。

**修改規則**：可編輯、可取消，不能刪除；每次修改記錄誰、何時、改了哪些欄位；已取消的任務不進模型但保留紀錄。

**民眾通知**：任務建立後列出範圍內與外溢環帶經過的里，產生通知清單與公告稿範本，可匯出，不實際發送。里長姓名與電話目前無開放資料，欄位留空、可匯入 CSV 補上。設計構想（不在本專案實作）：串接台北通 APP，推播給訂閱相關區域的使用者。

## 7. 回報
- demo 使用模擬資料，依環境熱區當機率分布產生 90 天回報，介面標示「模擬資料」。
- 匯入格式（JSON）欄位：經緯度、回報時間、鼠種（溝鼠、屋頂鼠、小家鼠、不確定）、辨識信心 0–1、目擊數量、跡證類型（活體、屍體、糞便、咬痕、鼠洞）。
- 升溫幅度 = 基礎值 × 辨識信心 × 跡證權重；影響半徑技術預設 150 m；半衰期於設定頁調整。

## 8. 設定頁
- 模型頁內的全幅側抽屜，即時預覽。
- 分頁：環境因子（每因子：範圍、強度、增加程度、飽和）、任務類型（四種各一組：扣除比例、承載量降幅與持續天數、外溢比例、環帶寬度）、回報（升溫、半衰期、半徑、跡證權重）、顯示（時間軸開關、熱區模式）。
- 關鍵參數（溝鼠族群成長率、活動半徑、投藥撲殺率、清消後回升時間）查文獻定預設值，其餘標示為「假設」；每個參數旁標示來源。
- 還原預設值、匯出匯入設定。

## 9. 身分
- 右上角下拉選單切換預設的 demo 角色（例如環保局病媒科承辦、萬華區清潔隊、外包廠商），只記錄不限制權限。
- 簡報說明：正式版接臺北通或公務帳號，依角色限制權限，稽核紀錄不可修改。

## 10. 儲存
- 任務、回報、設定存在瀏覽器，提供 JSON 匯出匯入。
- 預載 demo 情境：待討論。

### 參數預設值與來源

| 參數 | 預設 | 依據 |
|---|---|---|
| 族群成長率 r | 0.02 /日 | Bentley 1959；Byers 2019（下水道族群毒殺後約 6 個月回到原水準，含遷入） |
| 投藥撲殺率 | 第二代 95%、第一代 70%、其他 80% | Buckle 2012（第二代）；Richards 1981（bromadiolone 7 天 81%）；第一代為假設 |
| 環境清消 | 扣除 10%、K 降 30%、恢復半衰期 60 日、外溢 30% | 半衰期參考 Esther 2022（反彈延後約 85 天，畜牧場）；其餘假設 |
| 捕鼠籠 | 每日 2.3%（約每週 15%）、外溢 5% | 假設（Byers 2019 trappability 無移除比例） |
| 填補鼠洞 | K 降 20%、半衰期 120 日、外溢 15% | 假設（鼠洞約 6 個月內回到原水準，非同儕審查來源） |
| 外溢環帶 | 300 m | Byers 2019（親子代平均約 45 m，推定移動 0–353 m） |
| 回報影響半徑 | 150 m | Byers 2019（街廓尺度 30–150 m） |
| 猛禽提示外擴 | 1 km、2016 年以後 | Hong 2019（臺灣猛禽肝臟過半檢出抗凝血劑）；1 km ≈ 臺北鳳頭蒼鷹平均巢間距之半（推估，待核對） |

部分文獻為轉引（經 Byers 2019 系統性回顧），簡報前建議核對原文。
